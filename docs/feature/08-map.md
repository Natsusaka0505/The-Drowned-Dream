# 08 — 地圖與場景

## 規則

- 橫向捲軸，海底洞窟。
- 地圖結構參考銀河戰士：多個區域互相連通，可來回探索。

## 需求

- F-MAP-01：地圖由多個區域（Room）組成，區域間以出入口連接。
- F-MAP-02：玩家可在區域間自由往返（Boss 房亦可撤退）。
- F-MAP-03：場景中配置敵人、道具（封印道具、藥丸、氧氣瓶）、氧氣補給點。
- F-MAP-04：特定區域有憋氣 bonus 機制（見 [02-oxygen-breath.md](02-oxygen-breath.md) F-BRE-05）。
- F-MAP-05：SAN 低時地圖產生變化（見 [03-sanity.md](03-sanity.md) F-SAN-10）。
- F-MAP-06：攝影機跟隨玩家，並限制在當前區域邊界內。
- F-MAP-07：水下移動手感：有慣性 / 浮力（可調）。

## 待確認

- [待確認] 區域切換方式：同一 Scene 內大地圖 + 攝影機分區，或每區一個 Scene。（Jam 建議：單一 Scene，降低載入與合併衝突複雜度——最終由 core 決定）
- [待確認] 是否需要小地圖 / 全地圖 UI。
- [待確認] 區域數量與封印道具分布。
- [待確認] 是否有能力鎖區（取得某能力才能進入某區），Metroidvania 常見要素。
