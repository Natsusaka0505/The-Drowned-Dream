# 05 — 背包與道具

## 需求

### 背包
- F-INV-01：玩家有背包，可存放收集到的道具。
- F-INV-02：場景中的道具碰觸即拾取，放入背包。
- F-INV-03：可開啟背包 UI 查看道具與數量。
- F-INV-04：可從背包使用消耗型道具（或設定快捷鍵）。
- F-INV-05：道具以資料（ScriptableObject）定義，方便新增種類。

### 道具種類

| 道具 | 類型 | 效果 |
|---|---|---|
| 封印道具 | 關鍵道具 | 收集齊全後可封印 Boss（見 [07-boss-seal.md](07-boss-seal.md)），不可消耗/丟棄 |
| 藥丸 | 消耗品 | 恢復 SAN（不超過最大 SAN） |
| 氧氣瓶 | 消耗品 | 恢復氧氣（不超過上限） |

- F-INV-10：封印道具在 UI 顯示「已收集 / 總數」。
- F-INV-11：恢復類道具在數值已滿時[待確認：可否使用]。

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 封印道具總數 | 3 |
| 藥丸恢復 SAN | 30 |
| 氧氣瓶恢復氧氣 | 50 |
| 消耗品堆疊上限 | 9 |

## 待確認

- [待確認] 背包是否有格數上限。
- [待確認] 氧氣瓶是背包道具（手動使用）還是拾取立即生效。
- [待確認] 死亡時背包道具是否保留。
- [待確認] 是否有其他道具（地圖、鑰匙、能力升級等 Metroidvania 要素）。
