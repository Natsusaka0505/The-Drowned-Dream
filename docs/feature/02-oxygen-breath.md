# 02 — 氧氣、呼吸與憋氣

主題 Breath 的核心機制。玩家在「呼吸」與「憋氣」兩種狀態間切換。

## 狀態

| 狀態 | 效果 |
|---|---|
| 呼吸（預設） | 持續消耗氧氣值 |
| 憋氣 | 玩家隱形（敵人無法偵測），或依所在地圖觸發特定 bonus；有持續時間與 CD |

## 需求

### 氧氣值
- F-OXY-01：玩家有氧氣值（Oxygen），上限可調。
- F-OXY-02：呼吸狀態下氧氣隨時間持續下降。
- F-OXY-03：可透過道具（氧氣瓶等）或場景補給點補充氧氣，不超過上限。
- F-OXY-04：UI 顯示目前氧氣值。
- F-OXY-05：氧氣歸零時的後果：[待確認]（見下方）。

### 憋氣
- F-BRE-01：玩家按鍵進入憋氣狀態。
- F-BRE-02：憋氣有最大持續時間（肺活量），時間到自動結束。
- F-BRE-03：憋氣結束後進入 CD，CD 期間無法再次憋氣。
- F-BRE-04：憋氣期間玩家隱形——敵人不會偵測、追擊或攻擊玩家。
- F-BRE-05：特定地圖區域中，憋氣觸發該區域專屬 bonus（例如：通過特定機關、穿越水流）。bonus 類型以可擴充方式設計。
- F-BRE-06：UI 顯示憋氣剩餘時間與 CD。
- F-BRE-07：憋氣狀態需有明確視覺回饋（角色半透明、畫面效果、音效）。

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 氧氣上限 | 100 |
| 呼吸時氧氣消耗 | 1 / 秒 |
| 憋氣最大時間 | 5 秒 |
| 憋氣 CD | 8 秒 |

## 待確認

- [待確認] 氧氣歸零：直接死亡？還是持續扣 SAN / HP？
- [待確認] 憋氣期間氧氣是否停止消耗？（直覺上「憋氣 = 不消耗氧氣」，可作為策略選項）
- [待確認] 憋氣是否可以提早手動結束？提早結束 CD 是否縮短？
- [待確認] 憋氣中能否攻擊？攻擊是否會解除隱形？
- [待確認] 「肺活量」是否可成長（升級道具）。
