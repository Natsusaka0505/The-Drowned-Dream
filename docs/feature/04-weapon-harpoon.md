# 04 — 武器：魚槍

## 規則

- 開局持有一把魚槍，預設 3 支魚叉（彈藥）。
- 發射後魚叉留在場景（插在敵人/牆上或掉落），必須手動走過去撿回。

## 需求

- F-WPN-01：玩家可朝面向（或瞄準方向，[待確認]）發射魚叉。
- F-WPN-02：魚叉數量上限預設 3，數量為 0 時無法發射。
- F-WPN-03：魚叉命中敵人造成傷害；命中牆面/地形時停留在命中點。
- F-WPN-04：魚叉停止後成為可拾取物，玩家碰觸即撿回，數量 +1。
- F-WPN-05：UI 顯示目前持有魚叉數。
- F-WPN-06：魚叉在水中有射程/減速（可調）。

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 魚叉上限 | 3 |
| 傷害 | 1 |
| 射速 | 15 單位/秒 |
| 最大射程 | 10 單位 |
| 發射間隔 | 0.4 秒 |
