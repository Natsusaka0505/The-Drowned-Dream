# 06 — 場景生物（敵人）

## 規則

- 場景中有生物，玩家可選擇躲避（憋氣隱形）或攻擊（魚槍）。
- 靠近怪物會降低 SAN。

## 需求

- F-ENM-01：敵人有 HP，被魚叉命中扣血，歸零死亡。
- F-ENM-02：敵人有偵測範圍；玩家進入且未隱形時，敵人進入追擊/攻擊狀態。
- F-ENM-03：玩家憋氣隱形時，敵人無法偵測玩家，已追擊中的敵人失去目標。
- F-ENM-04：敵人有恐懼範圍（可與偵測範圍不同），玩家在範圍內持續掉 SAN（見 [03-sanity.md](03-sanity.md)）。
- F-ENM-05：敵人攻擊玩家造成的後果：[待確認]。
- F-ENM-06：敵人死亡時恢復玩家 SAN，並可掉落道具（可設定）。
- F-ENM-07：敵人以資料定義（HP、速度、範圍、SAN 影響），方便新增種類。
- F-ENM-08：敵人基本行為：巡邏 → 偵測 → 追擊/攻擊 → 失去目標 → 回到巡邏。

## 建議敵人種類（Jam 規模 2~3 種）

| 敵人 | 行為 |
|---|---|
| 巡游魚怪 | 固定路線巡邏，偵測後衝撞 |
| 觸手 | 固定位置，玩家靠近時攻擊 |
| 深淵之眼 | 不攻擊，但 SAN 下降範圍大 |

## 待確認

- [待確認] 玩家是否有 HP？或被攻擊直接扣 SAN / 氧氣？（目前需求未定義 HP）
- [待確認] 敵人是否重生（離開區域再回來）。
- [待確認] 實際敵人種類與數量。
