# 03 — SAN 值系統

## 規則

- 有「目前 SAN」與「最大 SAN」兩個值；目前 SAN 不可超過最大 SAN。
- 遇到怪物時 SAN 下降。
- 離開怪物範圍或擊殺怪物可恢復 SAN（不超過當下最大值）。
- 使用藥丸可恢復 SAN。
- 復活時影響最大 SAN（見 [09-death-respawn.md](../../09-death-respawn/SA/09-death-respawn.md)）。

## 需求

### 數值
- F-SAN-01：玩家有目前 SAN 與最大 SAN，UI 顯示兩者。2026-10-04：HUD 左上為「玩家頭像（頭相框）＋ HP 框 / SAN 框 / 氧氣泡泡」三列；SAN 框 + 藍紫填充條，數字疊在條上；失去的最大值以暗色遮住右側；減少時填充條閃白、殘影停一下再縮回。
- F-SAN-02：玩家位於怪物的「恐懼範圍」內時，SAN 持續下降（每種怪物可設定下降速率）；全域再乘上 `SanityConfig.DrainMultiplier`（2026-10-03 改為 **×2**）。
- F-SAN-03：離開所有怪物的恐懼範圍後，SAN 逐漸恢復，上限為目前最大 SAN。
- F-SAN-04：擊殺怪物時立即恢復一定 SAN（每種怪物可設定）。
- F-SAN-05：SAN **不會造成死亡**，只影響遊戲難度（低 SAN 效果）。SAN 0 = 效果最強。【已確認】
- F-SAN-06：憋氣隱形時，若在恐懼範圍內，SAN **仍會下降**。【已確認】

### 低 SAN 效果
- F-SAN-10：SAN 越低，地圖產生越明顯的變化（例如：畫面扭曲、色調變化、出現幻覺物件、牆面紋理改變）。依 SAN 百分比分段觸發。
- F-SAN-11：SAN 越低越容易**精神錯亂**（SAN 越低，錯亂發生越頻繁）。錯亂期間：【已確認 2026-10-03】
  - 每次按下 **A / W / D**（左 / 跳 / 右），有機率被隨機換成另外兩個方向之一；按住不放時沿用同一個替換結果，放開才重擲。
  - 按 **Space** 發射魚叉時，有機率**延遲射出**或**沒射出**（不會被換成方向）。
  - ~~平台跳躍下為「左右反轉」~~（2026-10-03 改為上述隨機替換）
- F-SAN-12：方向錯亂發生前需有預告（例如畫面閃爍、音效），讓玩家有機會察覺。
