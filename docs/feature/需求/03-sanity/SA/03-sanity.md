# 03 — SAN 值系統

## 規則

- 有「目前 SAN」與「最大 SAN」兩個值；目前 SAN 不可超過最大 SAN。
- 遇到怪物時 SAN 下降。
- 離開怪物範圍或擊殺怪物可恢復 SAN（不超過當下最大值）。
- 使用藥丸可恢復 SAN。
- 復活時影響最大 SAN（見 [09-death-respawn.md](../../09-death-respawn/SA/09-death-respawn.md)）。

## 需求

### 數值
- F-SAN-01：玩家有目前 SAN 與最大 SAN，UI 顯示兩者。
- F-SAN-02：玩家位於怪物的「恐懼範圍」內時，SAN 持續下降（每種怪物可設定下降速率）。
- F-SAN-03：離開所有怪物的恐懼範圍後，SAN 逐漸恢復，上限為目前最大 SAN。
- F-SAN-04：擊殺怪物時立即恢復一定 SAN（每種怪物可設定）。
- F-SAN-05：SAN **不會造成死亡**，只影響遊戲難度（低 SAN 效果）。SAN 0 = 效果最強。【已確認】
- F-SAN-06：憋氣隱形時，若在恐懼範圍內，SAN **仍會下降**。【已確認】

### 低 SAN 效果
- F-SAN-10：SAN 越低，地圖產生越明顯的變化（例如：畫面扭曲、色調變化、出現幻覺物件、牆面紋理改變）。依 SAN 百分比分段觸發。
- F-SAN-11：SAN 越低，玩家按方向鍵時有機率被替換成其他方向，SAN 越低機率越高。（平台跳躍下為「左右反轉」）
- F-SAN-12：方向錯亂發生前需有預告（例如畫面閃爍、音效），讓玩家有機會察覺。

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 最大 SAN | 100 |
| 恐懼範圍內下降 | 5 / 秒 |
| 離開後恢復 | 3 / 秒 |
| 擊殺恢復 | 15 |
| 地圖變化分段 | 70% / 40% / 20% |
| 方向錯亂機率 | SAN ≥ 50%：0%；之後線性增加至 SAN 0% 時 30% |
