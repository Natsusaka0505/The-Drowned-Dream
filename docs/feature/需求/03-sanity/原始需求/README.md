## 2026-10-03 口頭決議：精神錯亂

原文：

> san值越低要開始出現精神錯亂
> 越低時當走路案案下awd以及space發射弓箭時，會隨機替換成其他方向鍵

問答決議：
- 觸發方式：錯亂期間每次按鍵隨機（沿用「預告 → 錯亂一段時間」）
- 替換範圍：wsd互換，space會延遲發射或是不發射（開發解讀：「wsd」= A/W/D，S 未綁定功能）

## 2026-10-03 口頭決議：錯亂門檻與機率

> 掉san值從75％會出現精神錯亂，機率全部都加15％

開發解讀：門檻 50% → 75%；每次判定的錯亂機率整體 +15 個百分點（門檻處 0% → 15%，SAN 0 時 30% → 45%）。錯亂中的按鍵替換 / 發射異常機率未變動。
