# 02 — 氧氣、呼吸與憋氣

主題 Breath 的核心機制。玩家在「呼吸」與「憋氣」兩種狀態間切換。

## 狀態

| 狀態 | 效果 |
|---|---|
| 呼吸（預設） | **不消耗**氧氣【2026-10-03 改】 |
| 憋氣 | **消耗氧氣**；玩家隱形（敵人無法偵測），或依所在地圖觸發特定 bonus；有持續時間與 CD |

## 需求

### 氧氣值
- F-OXY-01：玩家有氧氣值（Oxygen），上限可調。
- F-OXY-02：~~呼吸狀態下氧氣隨時間持續下降。~~ → **只有憋氣時氧氣才會減少**，正常呼吸不消耗。【已確認 2026-10-03】
- F-OXY-03：洞窟為**封閉的固定氧氣空間**：沒有氣穴、補給點，也**沒有氧氣瓶**。氧氣只會減少，只有死亡復活時回滿。【已確認】
  - ⚠ 平衡風險：預設 100 氧氣 / 每秒 1 = 約 100 秒；走完 128×96 洞窟可能不夠，需企劃試玩後調整 `VitalsConfig` 的氧氣上限 / 消耗。
- F-OXY-04：UI 顯示目前氧氣值。
- F-OXY-05：氧氣歸零時，玩家 HP 持續下降（速率可調）；補回氧氣後停止扣 HP。【已確認】
  - 配合 F-OXY-02 調整：原型改為「氧氣歸零後**仍憋氣**才扣 HP，正常呼吸不扣」。`[待確認]` 是否改成氧氣歸零就不能憋氣。

### 憋氣
- F-BRE-01：玩家按鍵進入憋氣狀態。
- F-BRE-02：憋氣有最大持續時間（肺活量），時間到自動結束。
- F-BRE-02a：~~憋氣期間氧氣停止消耗。~~ → 憋氣期間**消耗氧氣**（見 F-OXY-02）。【2026-10-03 改】
- F-BRE-02b：憋氣中再按一次可**提早結束**；CD 依實際憋氣時間比例計算（可調最小 CD 比例）。【已確認】
- F-BRE-02c：憋氣中可以發射魚槍，但**發射會立即結束憋氣**（解除隱形）。【已確認】
- F-BRE-03：憋氣結束後進入 CD，CD 期間無法再次憋氣。
- F-BRE-04：憋氣期間玩家隱形——敵人不會偵測、追擊或攻擊玩家。
- F-BRE-05：特定地圖區域中，憋氣觸發該區域專屬 bonus（例如：通過特定機關、穿越水流）。bonus 類型以可擴充方式設計。
- F-BRE-06：UI 顯示憋氣剩餘時間與 CD。
- F-BRE-07：憋氣狀態需有明確視覺回饋（角色半透明、畫面效果、音效）。

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 氧氣上限 | 100 |
| 憋氣時氧氣消耗 | 1 / 秒（`[待確認]` 100 氧氣 = 共可憋氣 100 秒） |
| 憋氣最大時間 | 5 秒 |
| 憋氣 CD | 8 秒 |
| 氧氣歸零時 HP 下降 | 10 / 秒 |
| 提早結束最小 CD 比例 | 0.3 |
