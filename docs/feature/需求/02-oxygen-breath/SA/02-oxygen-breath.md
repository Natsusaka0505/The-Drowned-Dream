# 02 — 氧氣、呼吸與憋氣

主題 Breath 的核心機制。玩家在「呼吸」與「憋氣」兩種狀態間切換。

## 狀態

| 狀態 | 效果 |
|---|---|
| 呼吸（預設） | **不消耗**氧氣【2026-10-03 改】；憋氣 CD 結束後氧氣漸漸回滿【2026-10-04 改】 |
| 憋氣 | **消耗氧氣**；玩家隱形（敵人無法偵測），或依所在地圖觸發特定 bonus；有持續時間與 CD |

## 需求

### 氧氣值
- F-OXY-01：玩家有氧氣值（Oxygen），上限可調。
- F-OXY-06：**SAN 越低，氧氣上限越低**：上限 = 基礎上限 ×（SAN 0 時的比例 ～ 1，依 SAN 百分比線性），目前氧氣會被壓到新上限；SAN 回升時上限回升但不補氧。【已確認 2026-10-03】（[原文](../../00-overview/原始需求/2026-10-03-平衡調整.md)）
- F-OXY-02：~~呼吸狀態下氧氣隨時間持續下降。~~ → **只有憋氣時氧氣才會減少**，正常呼吸不消耗。【已確認 2026-10-03】
- F-OXY-03：洞窟內沒有氣穴、補給點，也**沒有氧氣瓶**。~~氧氣只會減少，只有死亡復活時回滿。~~ → **憋氣 CD 結束後，氧氣漸漸回復到上限**（約 6 秒從 0 回滿，`VitalsConfig.OxygenRefillSeconds`）；憋氣中與 CD 中不回復。【2026-10-04 改】
- F-OXY-04：UI 以**氧氣泡泡**顯示（最多 10 顆，依目前氧氣 / 目前上限的百分比；最後一顆依零頭縮小）。泡泡減少時播放破掉動畫（放大淡出），回復時從小長回。【2026-10-04 改】
- F-OXY-05：氧氣歸零時，**不論是否憋氣**，玩家 HP 每秒扣 20（可調）；補回氧氣後停止扣 HP。【已確認 2026-10-03】

### 憋氣
- F-BRE-01：玩家按鍵進入憋氣狀態。
- F-BRE-02：憋氣有最大持續時間（肺活量），時間到自動結束。**SAN 越低，最大憋氣時間越短**（依 SAN 百分比線性，SAN 0 時為基礎值的一定比例）。【已確認 2026-10-03】
- F-BRE-02a：~~憋氣期間氧氣停止消耗。~~ → 憋氣期間**消耗氧氣**（見 F-OXY-02）。【2026-10-03 改】
- F-BRE-02b：憋氣中再按一次可**提早結束**；CD 依實際憋氣時間比例計算（可調最小 CD 比例）。【已確認】
- F-BRE-02c：憋氣中可以發射魚槍，但**發射會立即結束憋氣**（解除隱形）。【已確認】
- F-BRE-03：憋氣結束後進入 CD，CD 期間無法再次憋氣。**CD 結束後還要等氧氣回滿才能再潛行**（氧氣泡泡全滿 = 可以潛行；未滿按鍵提示「氧氣尚未回滿，無法潛行」）。【2026-10-04 改】
- F-BRE-04：憋氣期間玩家隱形——敵人不會偵測、追擊或攻擊玩家。
- F-BRE-05：特定地圖區域中，憋氣觸發該區域專屬 bonus（例如：通過特定機關、穿越水流）。bonus 類型以可擴充方式設計。
- F-BRE-06：~~UI 顯示憋氣剩餘時間與 CD。~~ → 畫面**不顯示憋氣條**；憋氣時間（開始 / 結束時的隱形秒數、CD、CD 結束）先輸出到 Console（`[Breath]`）。【2026-10-04 改】
- F-BRE-07：憋氣狀態需有明確視覺回饋（角色半透明、畫面效果、音效）。

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 氧氣上限 | 100（SAN 0 時 ×0.5 `[待確認]`） |
| 憋氣時氧氣消耗 | 1 / 秒（`[待確認]` 100 氧氣 = 共可憋氣 100 秒） |
| 憋氣最大時間 | 5 秒（SAN 0 時 ×0.4 `[待確認]`） |
| 憋氣 CD | 4 秒（2026-10-04 由 8 秒縮短） |
| CD 結束後氧氣回滿秒數 | 6 秒【2026-10-04】 |
| 氧氣歸零時 HP 下降 | 20 / 秒【2026-10-03 改】 |
| 提早結束最小 CD 比例 | 0.3 |
