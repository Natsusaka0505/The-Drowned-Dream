# 08 — 地圖與場景

## 規則

- 橫向捲軸，海底洞窟。
- 地圖結構參考銀河戰士：多個區域互相連通，可來回探索。
- 地圖是**一張 2048×2048 的正方形圖片**，切成 **4×4 區塊**（每塊 512×512 px），整張圖就是整個地圖。【已確認】
- 洞窟是封閉空間，**沒有氣穴**（見 [02-oxygen-breath.md](../../02-oxygen-breath/SA/02-oxygen-breath.md) F-OXY-03）。【已確認】

## 需求

- F-MAP-01：地圖由 4×4 個區塊（Room）組成，區塊間以出入口連接。
- F-MAP-02：玩家可在區塊間自由往返（Boss 房亦可撤退）。
- F-MAP-03：場景中配置敵人、道具（封印道具、回復道具）、存檔點。
- F-MAP-04：特定區塊有憋氣 bonus 機制（見 [02-oxygen-breath.md](../../02-oxygen-breath/SA/02-oxygen-breath.md) F-BRE-05）。
- F-MAP-05：SAN 低時地圖產生變化（見 [03-sanity.md](../../03-sanity/SA/03-sanity.md) F-SAN-10）。
- F-MAP-06：攝影機平常**跟隨玩家**（限制在當前區塊邊界內）；第一次進 Boss 房時切到 Boss 特寫（見 07 F-BOSS-08）。【已確認】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-MAP-07：移動以**平台跳躍**為主（有重力、站在地面、跳躍）；水下手感以較低重力、較慢下落速度與慣性呈現（可調）。【已確認】
- F-MAP-08：牆壁 / 地板由一張**同尺寸的碰撞遮罩圖**定義（黑 = 牆、白 = 可通行）。美術改圖即可改地形。【已確認】
