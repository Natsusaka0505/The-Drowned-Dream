# 08 — 地圖與場景

## 規則

- 橫向捲軸，海底洞窟。
- 地圖結構參考銀河戰士：多個區域互相連通，可來回探索。
- 地圖是**一張 2048×2048 的正方形圖片**，切成 **4×4 區塊**（每塊 512×512 px），整張圖就是整個地圖。【已確認】
- 洞窟是封閉空間，**沒有氣穴**（見 [02-oxygen-breath.md](../../02-oxygen-breath/SA/02-oxygen-breath.md) F-OXY-03）。【已確認】

## 需求

- F-MAP-01：地圖由 4×4 個區塊（Room）組成，區塊間以出入口連接。
  - 2026-10-04 修正爬不上去的台階：原本薄石台左右交錯、每層高 2 單位，同側上一層就在頭頂 4 單位，角色（跳 2.58、身高 1.4）會撞頭。改為**所有 1 格厚的石台都是單向平台**（可從下方跳穿上去），厚方塊與牆維持實心。
  - 2026-10-04 再改：原型地圖的薄石台全部換成**隊友的 float1~6 平台 Prefab**（6×0.5 單位，輪流使用），放在掛 `PlatformGroup` 的 `Platforms` 底下，執行時自動設成 Ground Layer + 單向平台。階梯為左右交錯（中心 4.5 / 11.5 單位）、每層高 2，最上層在洞口正下方。已用程式模擬：從起點出發所有區塊（含支線房間爬回、Boss 房入口）都到得了。
  - 2026-10-04：浮台長度隨機（階梯 4~6 單位、其他 4~7 單位，固定種子每次重建相同），由建置腳本重排 float 實例的圖塊與碰撞框（保留左右端圖塊）；float 的 Dynamic 剛體執行時改 Static。階梯房下層天花板加寬挖開（4~27 格），最上階不會卡頭。最短 / 最長兩種情況都模擬過，全區可達。
  - 2026-10-04：單向浮台站上去後無法往下 → 新增「按住 S / ↓ 穿過浮台往下」（暫時忽略與該浮台的碰撞 0.35 秒）。

  - 2026-10-04 原型改版：**中央 2×2 打通成一間 Boss 房**（Boss 在地圖正中央），外圍一圈為探索路線：起點左上 → 上排往右 → 從右上地板洞掉進右側直井（(3,2)+(3,1) 打通，有之字石台可爬回）→ 落到右下 → 下排往左（憋氣屏障擋住往左下的門）→ 左下爬階梯上 (0,1) → 唯一入口進 Boss 房。起點地板另有洞通往支線小房間 (0,2)。

## 新地圖流程（2026-10-04 決議，美術圖尚未交付）

- 地圖改為**由下到上**：玩家起點在最下方，一路往上探索；**Boss 在地圖正中央**（2026-10-04 由「最左方正中間」改）。
- 組成：
  1. 遠景背景：沿用目前的 `background.png`。
  2. 地形：美術繪製的一張地圖圖，**只有地形**（不含障礙物與平台）。可通行處透明，**不透明處自動成為牆 / 地板**（`MapConfig.CollisionFromMapAlpha`，不用另畫遮罩）。
  3. 平台：用現有平台 Prefab（`Assets/Prefabs/float/float1~6`）手動擺放。
- 平台、怪物、寶箱、存檔點、Boss 區、玩家起點都放在一個**關卡 Prefab** 裡手動擺（`MapConfig.LevelPrefab`），重建場景時自動放入。
- 區塊切分改為可調參數（`MapConfig.Columns / Rows`），美術圖來了再依尺寸設定。
- 實作見 [SD-03 關卡 Prefab](../SD/SD-03-level-prefab.md)。
