# 08 — 地圖與場景

## 規則

- 橫向捲軸，海底洞窟。
- 地圖結構參考銀河戰士：多個區域互相連通，可來回探索。
- ~~地圖是一張 2048×2048 的正方形圖片，切成 4×4 區塊。~~（2026-10-03 改為下一條）
- 地圖是**一整片連通的洞窟**（參考泰拉瑞亞洞窟），**不分區塊、區塊之間沒有牆**；由程式依亂數種子**隨機生成**，尺寸 **128×96 單位**（碰撞遮罩 4096×3072 px）。【已確認 2026-10-03】
- 洞窟是封閉空間，**沒有氣穴**（見 [02-oxygen-breath.md](../../02-oxygen-breath/SA/02-oxygen-breath.md) F-OXY-03）。【已確認】

## 需求

- F-MAP-01：~~地圖由 4×4 個區塊（Room）組成~~ → 一整片連通洞窟：大洞廳、隧道、豎井、石台；起點在**地圖中央**，Boss 廳**隨機在地圖邊緣**。【已確認 2026-10-03】
- F-MAP-02：玩家可在洞窟內自由往返（Boss 廳亦可撤退）；生成器保證起點、所有道具、Boss 廳之間可以來回（平台跳躍可達性檢查）。
- F-MAP-03：場景中配置敵人、道具（封印道具、回復道具）、存檔點。
- F-MAP-04：特定區塊有憋氣 bonus 機制（見 [02-oxygen-breath.md](../../02-oxygen-breath/SA/02-oxygen-breath.md) F-BRE-05）。
- F-MAP-05：SAN 低時地圖產生變化（見 [03-sanity.md](../../03-sanity/SA/03-sanity.md) F-SAN-10）。
- F-MAP-06：攝影機平常**跟隨玩家**（只限制在整張地圖範圍內，不再受區塊限制）；第一次進 Boss 廳、以及撿齊所有封印碎片時，切到 Boss 廳數秒再切回玩家（見 07 F-BOSS-08/09）。【已確認 2026-10-03】
- F-MAP-07：移動以**平台跳躍**為主（有重力、站在地面、跳躍）；水下手感以較低重力、較慢下落速度與慣性呈現（可調）。【已確認】
  - 跳躍高度固定：短按或長按都跳一樣高（不做長按跳更高）；按住跳躍鍵不放 → 落地後自動繼續跳。【已確認 2026-10-03】
  - 下降時重力加倍（`MovementConfig.FallGravityMultiplier` = 2），最大下落速度 12，避免下降太慢。【2026-10-03 調整】
- F-MAP-09：地圖後方有一張**遠景背景圖**（`Assets/Art/Background/background.png`），不參與碰撞，隨攝影機做視差捲動。【已確認】
- F-MAP-10：地形外觀由碰撞遮罩**自動貼 Terrain 圖塊（Tilemap）**，不再使用整張地圖圖；洞穴空間後方墊一層**半透明暗色背景牆**，遠景隱約可見。【2026-10-03】
- F-MAP-08：牆壁 / 地板由一張**碰撞遮罩圖**定義（黑 = 牆、白 = 可通行），由洞窟生成器產生。【已確認】
- F-MAP-11：憋氣屏障放在**通往 Boss 廳的入口隧道**；敵人、道具、存檔點、幻覺物件由生成器自動擺在可到達的位置。【已確認 2026-10-03】
