# SD-02 — 地圖：2048×2048 圖片、4×4 區塊、Tilemap 可行性評估

對應需求：[SA/08-map.md](../SA/08-map.md)

## 前提

| 項目 | 值 |
|---|---|
| 地圖圖片 | 2048×2048 px，一張 = 整個地圖 |
| 區塊 | 4×4，每塊 512×512 px |
| 碰撞 | 另一張同尺寸遮罩圖（黑 = 牆） |
| PPU（預設） | 32 → 每區塊 16×16 單位，整張地圖 64×64 單位 |
| 角色大小 | 約 0.75×1.5 單位（24×48 px），跳躍高度約 2.5 單位（80 px） |

## Tilemap 可以用在哪裡

| 用途 | 可行性 | 說明 |
|---|---|---|
| **碰撞** | ✅ 推薦，已實作 | 遮罩圖每 16 px 取樣一次 → 放一格碰撞 Tile → `TilemapCollider2D` + `CompositeCollider2D` 合併成平滑外框。美術改遮罩圖後按 **Rebuild Map** 即可。 |
| **地圖美術（整張圖）** | ⚠️ 不建議用 Tilemap | 美術是一張完整的畫，不是重複圖塊。切成 Tile 再拼回去沒有好處，反而多出接縫與管理成本。直接用一張 Sprite 當背景最簡單。 |
| **區塊切分** | ✅ 不需要 Tilemap | 4×4 只是座標切分，用 16 個 `Room` 觸發框即可。 |
| **攝影機** | — | 攝影機與 Tilemap 無關，見下方「攝影機」。 |

**結論：碰撞用 Tilemap（由遮罩圖自動產生），美術用整張 Sprite。** 原型已依此實作（`Editor/MapBuilder.cs`）。

### 碰撞 Tile 大小的取捨

| 取樣格 | 碰撞格數 | 精細度 | 備註 |
|---|---|---|---|
| 32 px（1 單位） | 64×64 = 4,096 | 粗 | 斜坡會變成大階梯 |
| **16 px（0.5 單位）** | 128×128 = 16,384 | 中，**預設** | 與角色尺寸相稱 |
| 8 px（0.25 單位） | 256×256 = 65,536 | 細 | 合併後效能仍可接受，產生時間較長 |

在 `MapConfig.MaskCellPixels` 可調整。

### 遮罩圖規則（給美術）

- 與地圖圖**同尺寸、同對齊**（2048×2048）。
- **黑色 = 牆 / 地板 / 平台**（實心），**白色 = 可通行**。
- 每 16×16 px 取中心點判斷，所以牆最薄要 16 px，通道最窄建議 64 px（2 單位）以上，角色才過得去。
- 門 / 通道高度建議 ≥ 128 px（4 單位）。
- 跳躍可及高度約 80 px，平台之間的高低差不要超過 70 px。

## 攝影機（已決定）

依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)：**平常跟隨玩家**，第一次進 Boss 房時**切到 Boss 特寫**再切回玩家。實作：`Camera/GameCamera`（`SwitchToPlayer` / `SwitchToBossRoom`）。

| 項目 | 原型值 | 說明 |
|---|---|---|
| 跟隨畫面大小 | `orthographicSize = 6`（12 單位高） | 小於區塊（16 單位），垂直方向會跟隨並夾在區塊邊界內 |
| 特寫畫面大小 | 4.5 | Boss 特寫時不受區塊邊界限制 |
| 16:9 寬度 | 約 21 單位 | 比區塊寬，水平方向會置中於區塊、左右看得到相鄰區塊 `[待確認] 是否遮黑` |

（評估時曾考慮的「一次顯示整個區塊」方案：把 `_followSize` 設成 8 即可切換。）

## 實作流程

```
MapConfig（地圖圖、遮罩圖、4×4、PPU 32、取樣 16px）
   │
   ├─ 地圖圖 → Sprite（左下角對齊原點）→ Map/Background
   ├─ 遮罩圖 → 每格取樣 → Tilemap(Collision, Layer=Ground)
   │                         └ TilemapCollider2D + CompositeCollider2D
   └─ 4×4 → Map/Room_c_r（Trigger，攝影機邊界、Boss 房判定）
```

- 遮罩圖以檔案直接讀取，不需要開 Read/Write。
- 碰撞層的 `TilemapRenderer` 預設關閉，除錯時可打開看紅色碰撞格。
- 美術交付正式圖後：把圖放進專案 → 在 `Assets/Data/Map/MapConfig` 換掉兩張圖 → 選單 **Rebuild Map**。
