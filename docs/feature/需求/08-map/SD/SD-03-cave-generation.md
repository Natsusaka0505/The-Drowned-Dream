# SD-03 — 隨機洞窟生成（泰拉瑞亞式連通洞窟）

對應需求：[SA/08-map.md](../SA/08-map.md) F-MAP-01/02/06/08/10/11、[07 F-BOSS-01/09](../../07-boss-seal/SA/07-boss-seal.md)

取代 SD-02 的「4×4 區塊」與 SD-01 的手擺關卡配置。碰撞 Tilemap / 地形自動貼圖沿用 SD-02。

## 尺寸

| 項目 | 值 |
|---|---|
| 地圖 | 128×96 單位（PPU 32 → 遮罩 4096×3072 px） |
| 格子 | 16 px = 0.5 單位 → 256×192 格 |
| 角色 | 0.7×1.4 單位 ≈ 2×3 格 |
| 跳躍 | 約 2.5 單位 ≈ 5 格；可達性檢查保守取「上升 ≤ 4 格」 |

## 生成流程（`Editor/CaveGenerator`，純 C#，固定種子 → 結果固定）

1. **粗格細胞自動機**：以 4×4 格為一粗格（2 單位），隨機填牆（`FillPercent`）→ 平滑數次 → 放大回細格，再以細格平滑一次讓邊緣圓滑。
2. **外框**：地圖四周 `BorderCells` 格實心。
3. **起點洞廳**：地圖中央挖一個平底洞廳。
4. **Boss 廳**：隨機選左 / 右 / 下邊緣挖平底大洞廳；從廳的側面挖一段**水平入口隧道**，再以隨機漫步挖向地圖中央直到接上洞穴。
5. **憋氣屏障**：放在入口隧道的水平段（離廳 3 單位、寬 2 單位），擋滿隧道高度；外觀為水流（`Art/Map/Props/prop_waterfall.png`）。
6. **連通**：從起點 flood fill；其他空洞太小就填實，夠大就挖隧道接回主洞。
7. **清理**：寬度 < 3 格或高度 < 4 格的縫隙填實（角色進不去、會卡住）。
8. **稀疏浮台**：高的空間每 4 格（2 單位）一層鋪浮台，長度 3~6 格、間隔隨機（`CaveGenConfig.LedgeGap`），不疊在下一層正上方（避免撞頭）；上下各 3 格要空，底下仍可走過。
9. **可達性修補**（迴圈）：
   - 站立點 = 空 2×3 格且腳下有地。
   - 移動：左右走、走出邊緣下落、跳躍（上升 ≤ 4 格、水平 ≤ 3~5 格，路徑需有淨空）。
   - 正向 BFS（起點能到哪）+ 反向 BFS（哪裡能回起點）。
   - 「能到但回不來」的坑 → 在坑內最高站立點上方加石台；放不下就把整排坑底墊高一格。
   - 「上不去」的洞穴 → 由低到高找第一個下方放得下石台的點補一塊，一層層接到可到達處。
   - 品質門檻：可來回站立點 ≥ 1200、物件放滿 ≥ 8 成；不合格就換下一個種子（Console 會印出原因與實際使用的種子）。
10. **擺物件**（只用「能到也能回」的站立點，Boss 廳除外）：

| 物件 | 規則 |
|---|---|
| 存檔點 | 起點 1 個 + Boss 入口隧道外 1 個 + 其餘最遠點取樣 |
| 封印碎片 | 3 個，離起點與彼此最遠 |
| 鎮靜藥丸 / 海草繃帶 | 隨機、保持間距 |
| 巡游魚怪 | 站在地面，左右各有 ≥ 巡邏距離的身高淨空 |
| 觸手 | 平地 |
| 深淵之眼 | 平地 |
| 幻覺物件 | 上方空間大的位置 |
| Boss / 祭壇 / BossArea | Boss 廳內（BossArea = 整個 Boss 廳的觸發框） |

所有敵人（含 Boss）碰撞框底部貼地，與玩家同一高度帶（F-ENM-00）。

數量、間距、種子都在 `Assets/Data/Map/CaveGenConfig`（Inspector 可調）。

## 輸出

- 碰撞遮罩 `Assets/Art/Map/MapMask_Cave.png`（黑 = 牆），`MapConfig.CollisionMask` 指向它。
- **Build Prototype Scene** 每次依種子重新生成遮罩與物件位置；換種子 = 換一張新地圖。
- **Rebuild Map** 只依現有遮罩重建地形（不重新生成、不動物件）。

## 圖層

| 圖層 | Order |
|---|---|
| 遠景（視差） | −100 |
| 背景牆（背景素材 3×3，依空格四周的牆挑圖塊，半透明） | −8 |
| 背景牆裂紋 | −7 |
| 地形 | −6 |
| 裝飾 | −5 |

`MapConfig.Terrain` 有設定時不再畫整張地圖圖（`Map/Background`）。

## 攝影機

- 平常跟隨玩家，**只限制在地圖範圍內**（`GameCamera._mapBounds`）。
- `BossArea`：第一次進 Boss 廳、或撿齊封印碎片（`PlayerStatus.SealCountChanged` 達到需求數）時，鎖輸入 → 鏡頭切到 Boss 數秒 → 切回玩家。

## 效能

一次生成約 1~20 秒（只在 Build Prototype Scene 時跑）；換種子若遇到不合格會自動往後試。

## 已知限制

- 可達性檢查是格子近似，可能有「技術上跳得到、實際很難跳」的位置；石台補得偏密以降低風險。
- 手改遮罩後按 Rebuild Map 只更新地形，物件位置不會重算。
