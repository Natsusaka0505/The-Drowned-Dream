# 07 — Boss 與封印

## 規則

- 遊戲目標：收集所有封印道具，封印 Boss。
- 抵達 Boss 時若封印道具未收集齊全，玩家可以返回探索，但 Boss 會持續攻擊玩家。

## 需求

- F-BOSS-01：Boss 位於固定區域（Boss 房）。
- F-BOSS-02：玩家進入 Boss 房時，檢查背包封印道具數量。
- F-BOSS-03：封印道具齊全 → **Boss 照樣啟動攻擊**（2026-10-04 改），玩家要在攻擊下走到祭壇 → 可進行封印（互動鍵 / 靠近祭壇等，[待確認]）→ 封印成功 → 進入結局（見 [01-story.md](../../01-story/SA/01-story.md)）。
- F-BOSS-04：~~封印道具不齊 → Boss 啟動~~ → 進 Boss 房 Boss 一律啟動並持續攻擊玩家（2026-10-04 改）；Boss 房出口保持開放，玩家可撤退。
- F-BOSS-05：玩家離開 Boss 房後 Boss 停止追擊（或[待確認]：Boss 是否追出房間）。
- F-BOSS-06：進入 Boss 房時提示封印道具收集進度。
- F-BOSS-08：**第一次**進入 Boss 房時，鏡頭切到 Boss 特寫數秒再切回玩家；之後再進入不再播放。【已確認】2026-10-03：鏡頭以平移方式移到 Boss（`GameCamera._switchSmoothTime` 0.5），特寫 3.5 秒（`BossArea._closeUpSeconds`）後平移回玩家。（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-BOSS-07：Boss 存在時對玩家 SAN 有大範圍影響。
- F-BOSS-13：Boss **整體放大 2 倍**（外觀約 16.6×12、判定 8×12，腳底貼地；恐懼範圍 18），位置在**地圖正中央**的大 Boss 房（原型地圖與關卡範本都是）；Boss 特寫畫面大小改為 8。【2026-10-04】
- F-BOSS-12：Boss 外觀使用美術動畫 `boss.gif`（2026-10-04，方案 A）：拆成 33 格 PNG（`Assets/Art/Boss/boss_00~32.png`，裁掉透明邊、縮為 70%），由 `World/SpriteFrameAnimator` 照原本每格時間循環播放；約 8.3×6 單位，判定範圍維持寬 4、高 6。GIF 只有 256 色與非全透明即全不透明的邊緣，`[待確認]` 之後請美術匯出 PNG 序列圖替換同名檔案即可。
- F-BOSS-10：封印道具共 **5 個**；前 4 個在地圖上的黑寶箱，**第 5 個要第一次進 Boss 房（Boss 啟動）後才出現**：從預設的幾個候選點隨機選一個放出黑寶箱，3 秒後提示「遠處傳來低語……最後一尊雕像出現在洞窟某處」。候選點是 `HiddenSealSpawner` 的子物件，可自由增減 / 移動。【2026-10-04】
- F-BOSS-11：**全圖攻擊**：第一次進 Boss 房後 Boss 被喚醒，玩家離開 Boss 房時，每 5 秒在玩家附近交替使用【落雷（玩家所在區塊、2 道）】與【追蹤彈（從玩家上方兩側出現、可穿牆）】。全圖攻擊**只扣 HP、不扣 SAN**；扣 SAN 的攻擊（咆哮）與 Boss 恐懼範圍只在 Boss 房附近。**封印完成才停**，死亡復活不重置。參數在 `BossController`「全圖攻擊」區。【2026-10-04】
- F-BOSS-09：Boss 攻擊依序輪替（2026-10-04；`BossController._attackOrder` 可調順序，招與招間隔 2 秒）：
  | 攻擊 | 說明 |
  |---|---|
  | 扇形彈幕 | 原本的 3 發扇形彈 |
  | 觸手掃地 | 整條地面預告 1 秒 → 判定塊由 Boss 這側掃到另一側（0.9 秒），高 1.2，要跳起來躲 |
  | 追蹤彈 | 往上兩側射出 2 顆慢速追蹤彈（轉向 100°/秒，5 秒消失） |
  | 落雷 | 以玩家為中心預告 3 道直柱（間距 3），依序落下 |
  | 咆哮 | 蓄力閃爍 0.6 秒 → 畫面震動 + 播放咆哮音效，房內未隱形的玩家扣 SAN 20 |
  - 使用者原話為「落雷」；實作為從上方落下的直柱攻擊。2026-10-04：落下時播放閃電特效 **FX Lightning II free 的 `fx_lightning_02`**（拉伸到直柱高度，寬 4、存在 0.5 秒，`BossController._lightningFx*` 可調），判定色塊淡化成底色；全圖落雷同樣套用。
