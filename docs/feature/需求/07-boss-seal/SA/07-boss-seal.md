# 07 — Boss 與封印

## 規則

- 遊戲目標：收集所有封印道具，封印 Boss。
- 抵達 Boss 時若封印道具未收集齊全，玩家可以返回探索，但 Boss 會持續攻擊玩家。

## 需求

- F-BOSS-01：Boss 位於固定區域（Boss 房）。
- F-BOSS-02：玩家進入 Boss 房時，檢查背包封印道具數量。
- F-BOSS-03：封印道具齊全 → **Boss 照樣啟動攻擊**（2026-10-04 改），玩家要在攻擊下走到祭壇 → 可進行封印（互動鍵 E）→ 封印成功 → 進入結局（見 [01-story.md](../../01-story/SA/01-story.md)）。
- F-BOSS-20：**兩座祭壇**（2026-10-04）：Boss 左右各一座（靠牆，避開鎖鏈）。封印道具齊全時在祭壇旁按 E 啟動該座（綠光變亮），**兩座都啟動才封印成功**。提示：靠近時「按 E 啟動祭壇（x / 2）」或「這座祭壇已啟動，前往另一座祭壇」；啟動第一座「祭壇已啟動！前往邪神另一側的祭壇，還差 1 座」；第二座「祭壇共鳴……封印完成」→ 結局。進 Boss 房與背包說明也改為「啟動左右兩座祭壇」。
- F-BOSS-21：Boss 下方浮岩**頂面可站立**（單向平台：可從下方跳上、按 S 穿過往下；可從兩側浮台跳上去）。彈幕不會被單向平台擋住（浮岩、浮台都會穿過）。【2026-10-04】
- F-BOSS-22：彈幕外觀放大 1.6 倍（判定大小不變，`_projectileArtScale` / `EnemyData._bubbleArtScale` 可調），並加**閃光**：後方紅色柔光 + 小範圍紅色點光源，尖峰型閃爍、每顆相位不同；閃爍速度放慢為一半，子彈本體不透明度跟著在 0.35 ~ 1 間閃。【2026-10-04】
- F-BOSS-23：**精靈變身演出**（第一次進 Boss 房，2026-10-04；取代原本的鏡頭特寫）：Boss 一開始隱藏 → 鎖輸入，精靈出現在玩家身旁說「終於上當了……」→ 鏡頭轉向 Boss、精靈飛過去說「謝謝你一路幫我把雕像帶回來。」（沒集齊：「可惜你沒湊齊雕像，也封印不了我。」）→「這片深海，就是你的墓。」→ 精靈轉紅、抖動、放大 3 倍、光變強 → **全畫面閃白**、Boss 現身咆哮、鏡頭震動 → 特寫 3.5 秒 → 切回玩家、Boss 啟動。台詞由左下精靈對話框說，台詞與各段秒數在 `BossArea` 可調。【2026-10-04】精靈改為主角頭上的**海兔**：演出一開始海兔從玩家頭頂直直飄起（播「跳」畫格、邊飄邊放大，`BossArea._leaveHeadSeconds` 0.6 秒、`_leaveHeadLift` 1.2 單位），在頭頂上方說第一句，再從那裡飛向 Boss，之後流程不變；場景沒有海兔時退回舊的精靈圖。
- F-BOSS-24：**集齊封印道具後 Boss 強化**（2026-10-04）：攻擊間隔（房內 2 秒、全圖 5 秒）×0.5；扇形彈、追蹤彈、落雷（房內與全圖）各 +1 發（掃地、咆哮不變）。強化時提示「邪神察覺到雕像的力量……攻擊變得更加猛烈！」（進房時已集齊則併在進房提示）。`BossController._empoweredIntervalMultiplier / _empoweredExtraCount / _empoweredMessage` 可調。
- F-BOSS-25：**浮岩地刺**（2026-10-04）：Boss 啟動後，玩家站在浮岩上時每 2.2 秒（強化時 ×0.5）在腳下冒一組地刺（寬 3、最高 1.9，預告 0.8 秒、判定 0.45 秒、傷害同 Boss），與一般出招各自獨立；剛站上去 0.6 秒後才第一次冒；強化時另在浮岩隨機位置多冒一組。特效 `SpikeEruption`：預告為地面裂縫由中間往兩側發紅光、碎石顫動、地底紅光脈動加快；發動時骨刺（程式產生的骨刺圖：根部暗、尖端骨白、左亮右暗、高光脊線）由中間往兩側依序彈出（高低傾角不一、回彈），噴碎石與塵霧、紅光閃一下、鏡頭小震；收回時下沉淡出。數值在 `BossController` 的「浮岩地刺」區可調。
