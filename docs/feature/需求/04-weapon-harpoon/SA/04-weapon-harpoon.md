# 04 — 武器：魚槍

## 規則

- 開局持有一把魚槍，預設 3 支魚叉（彈藥）。
- 發射後魚叉留在場景（插在敵人/牆上或掉落），必須手動走過去撿回。

## 需求

- F-WPN-01：玩家按 **Space** 朝**面向（左/右）**發射魚叉。【已確認】
- F-WPN-02：魚叉數量上限預設 3，數量為 0 時無法發射。
- F-WPN-03：魚叉接觸 enemy 時計為一次「被攻擊」，之後往下掉；接觸場地（牆 / 地形）時插在接觸點。【已確認】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-WPN-04：魚叉停止後成為可拾取物，玩家碰觸即撿回，數量 +1。
- F-WPN-05：UI 顯示目前持有魚叉數。
- F-WPN-06：魚叉以**拋物線**飛行（飛行速度、重力可調）。【已確認】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）

## 預設參數（可調）

| 參數 | 預設 |
|---|---|
| 魚叉上限 | 3 |
| 重力（拋物線下墜） | 6 單位/秒² |
| 射速 | 15 單位/秒 |
| 發射間隔 | 0.4 秒 |

- F-WPN-UI（2026-10-04）：魚叉外觀改用美術 `Speargun.png`（水平、槍頭朝右，往左飛時上下翻轉）；HUD 右上角剩餘數量改為**魚叉圖示**（每支一個斜放圖示，用掉的半透明）；背包魚叉欄位用魚槍圖 `gun_icon.png`。
