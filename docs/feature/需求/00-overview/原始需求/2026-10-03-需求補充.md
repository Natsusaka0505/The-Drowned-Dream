## 原文

## 同日問答決議

| 問題 | 決議 |
|---|---|
| 移動方式 | 洞窟，平台跳躍為主 |
| 死亡條件 | 氧氣不足會開始扣 HP；SAN 影響遊戲難度；只有 HP 歸零才會死亡 |
| 魚槍瞄準 | 只能左右 |
| 憋氣規則 | 憋氣時不耗氧、可提早手動結束、攻擊會解除隱形、隱形時仍會掉 SAN |
| Space 改為發射後 W/↑、S/↓ | W/↑ 跳躍，S/↓ 不用 |
| 地圖碰撞定義 | 另一張碰撞遮罩圖 |
| 攝影機 | 請評估 tile mapping 的可行性（見 SD-02） |
