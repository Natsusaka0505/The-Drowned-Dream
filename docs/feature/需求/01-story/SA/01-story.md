# 01 — 角色與故事

## 背景

- 主角：一名男子，夢見海底洞窟中藏有克蘇魯邪神的寶藏，因此前往洞窟探險。
- 結局：通關（封印 Boss）後，揭示整趟冒險**全都是夢**——而這場夢成為他真正出發尋寶的動機。

## 需求

- F-STORY-01：開場呈現主角做夢 / 被寶藏吸引的動機（文字、插圖或簡短演出皆可）。
- F-STORY-02：封印 Boss 後進入結局演出，呈現「醒來 → 原來是夢 → 決定出發尋寶」。
- F-STORY-03：結局後回到標題畫面或顯示製作名單。（2026-10-03 決議：回到封面）
- F-STORY-04：遊戲啟動先顯示封面（封面底圖 + Start / Quit 按鈕）。Start → 開場文字 → 遊玩；Quit → 結束遊戲。封面播放開場 BGM。（2026-10-03 決議）
  - Start / Quit 上下排列（Start 在上），位於標題字與角色之間（預設欄中心在封面 x 46%、離底部 47%，上下間距 45，`TitleScreen._buttonColumnX / _buttonColumnY` 可調）。封面完整顯示（畫面比例不是 16:9 時上下或左右補黑邊）。可用滑鼠點擊；滑鼠移上 / 鍵盤手把選取時放大。
