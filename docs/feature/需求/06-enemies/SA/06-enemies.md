# 06 — 場景生物（敵人）

## 規則

- 場景中有生物，玩家可選擇躲避（憋氣隱形）或攻擊（魚槍）。
- 靠近怪物會降低 SAN。

## 需求

- F-ENM-00：所有敵人（含 Boss）**站在地面上**，與玩家可站立的高度一致；巡游魚怪只在所在區塊的空地內巡邏 / 追擊，不穿牆。【已確認 2026-10-03】
- F-ENM-01：敵人記錄「被攻擊次數」，被魚叉命中達上限即死亡（每種敵人可設定上限）。【已確認】**基本怪物（魚怪 / 觸手 / 深淵之眼）一律 3 次。**【2026-10-03】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-ENM-02：敵人有偵測範圍；玩家進入且未隱形時，敵人進入追擊/攻擊狀態。
- F-ENM-03：玩家憋氣隱形時，敵人無法偵測玩家，已追擊中的敵人失去目標。
- F-ENM-04：敵人有恐懼範圍（可與偵測範圍不同），玩家在範圍內持續掉 SAN（見 [03-sanity.md](../../03-sanity/SA/03-sanity.md)）。
- F-ENM-05：敵人攻擊玩家扣 **HP**（每種敵人可設定傷害），玩家受傷後有短暫無敵時間。【已確認：玩家有 HP】
  - ~~被怪物打中一次 HP 直接歸零~~ → **被任何怪物攻擊（含 Boss）打中一次固定扣最大 HP 的 25%**（`VitalsConfig.EnemyHitHpRatio`；設 0 則改用各攻擊自己的傷害值）。【2026-10-04 改】
- F-ENM-06：敵人死亡時恢復玩家 SAN，並可掉落道具（可設定）。
- F-ENM-07：敵人以資料定義（HP、速度、範圍、SAN 影響），方便新增種類。
- F-ENM-08：敵人基本行為：**左右移動**巡邏 → 偵測 → 左右追擊 / 攻擊判斷 → 失去目標 → 回到巡邏。【已確認】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-ENM-09：敵人 status：被攻擊次數、移動速度、偵測範圍、攻擊範圍、移動狀態、是否偵測到玩家。
- F-ENM-11：小怪攻擊手段（2026-10-04）。參數都在各自的 `EnemyData`：
  | 怪物 | 攻擊 | 說明 |
  |---|---|---|
  | 巡游魚怪 | 追撞 | 原本的接觸傷害 |
  | 巡游魚怪 | 蓄力衝刺 | 追擊中玩家在 5 單位內 → 停下閃紅 0.5 秒 → 以速度 12 衝 0.35 秒；冷卻 2.5 秒 |
  | 巡游魚怪 | 吐泡泡彈 | 追擊中每 3 秒朝玩家吐一顆慢速泡泡彈（速度 3），**可被魚叉打破** |
  | 觸手 | 橫戳 | 原本的伸長攻擊（2.5 單位內） |
  | 觸手 | 地面突刺 | 玩家在 7 單位內但不在橫戳範圍 → 玩家腳下預告 0.7 秒後冒出地刺；每 3 秒一次。2026-10-04 動畫：暗紅預測線 → 3 根骨白色尖刺由中間往兩側依序彈出（略超出再回彈），判定結束後 0.2 秒縮回地面（`TelegraphStrike.WithSpikes`） |
  | 深淵之眼 | 凝視光束 | 玩家在 9 單位內 → 瞄準線預告 1 秒 → 直線光束 0.35 秒（碰牆截斷），命中另扣 SAN 15；每 3.5 秒一次。光束特效用 **FX Lightning II free 的 `fx_lightning_01`**（沿光束方向拉伸，寬 2.4、存在 0.45 秒，`EnemyData._beamFx*` 可調） |
  - 所有攻擊在玩家憋氣隱形時都打不到（沿用 F-ENM-03）。
  - 敵人移動時前方有牆 / 平台側面會停下（手擺關卡不設活動範圍也不會穿牆）。
- F-ENM-12：外觀（2026-10-04）：巡游魚怪維持紅色方塊；深淵之眼改為**眼球**（會眨眼，**瞳孔跟著玩家轉**，玩家隱形時回到正中；分層：`_baseSprite` 眼白 / `_lookSprite` 瞳孔 / `_animFrames` 眼皮）；觸手改為**海蝶**（依美術參考圖：青色身體、黑色粗框、頭與身體各一個黑色漩渦斑、頭上兩根觸角、寬扇形翅膀拍動），橫戳改成朝玩家方向噴出觸鬚（判定不變）。圖為程式繪製暫用，設定在 `EnemyData._animFrames / _animDurations / _tendrilSprite`。
- F-ENM-10：一般敵人外觀微微上下浮動（只動外觀、碰撞框不動；每隻相位隨機，`EnemyAI._bobHeight` 0.08 / `_bobSpeed` 2.5 可調）。Boss 不浮動。【2026-10-03】

## 建議敵人種類（Jam 規模 2~3 種）

| 敵人 | 行為 |
|---|---|
| 巡游魚怪 | 固定路線巡邏，偵測後衝撞 |
| 觸手 | 固定位置，玩家靠近時攻擊 |
| 深淵之眼 | 不攻擊，但 SAN 下降範圍大 |
