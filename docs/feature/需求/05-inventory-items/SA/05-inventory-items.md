# 05 — 背包與道具

## 需求

### 背包
- F-INV-01：道具狀態檢視，可檢視收集到的道具，以及道具內容。
- F-INV-02：場景中的道具碰觸即拾取，
- F-INV-03：可開起檢視 UI 查看道具與數量。
- F-INV-04：道具以資料（ScriptableObject）定義，方便新增種類。

### 道具種類

| 道具 | 類型 | 效果 |
|---|---|---|
| 封印道具 | 關鍵道具 | 收集齊全後可封印 Boss（見 [07-boss-seal.md](../../07-boss-seal/SA/07-boss-seal.md)），不可消耗/丟棄 |
| 鎮靜藥丸 | 回復道具 | 回復 SAN（不超過最大 SAN） |
| 海草繃帶 | 回復道具 | 回復 HP（不超過上限） |

- F-INV-12：回復道具有「SAN 回復數值」與「HP 回復數值」兩個欄位，可各自設定。【已確認】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-INV-13：**沒有氧氣瓶**（見 02 F-OXY-03）。【已確認】
- F-INV-14：玩家只記錄「武器（魚叉）數量」與「封印道具數量」兩種，因此回復道具**撿到即生效、不進背包**。【依 script 分類推定，待確認】

- F-INV-10：封印道具在 UI 顯示「已收集 / 總數」。
- F-INV-11：恢復類道具在數值已滿時[待確認：可否使用]。
