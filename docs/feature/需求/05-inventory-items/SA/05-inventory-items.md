# 05 — 背包與道具

## 需求

### 背包
- F-INV-01：道具狀態檢視，可檢視收集到的道具，以及道具內容。
- F-INV-02：場景中的道具碰觸即拾取，
- F-INV-03：可開起檢視 UI 查看道具與數量。
- F-INV-04：道具以資料（ScriptableObject）定義，方便新增種類。

### 道具種類

| 道具 | 類型 | 效果 |
|---|---|---|
| 封印道具 | 關鍵道具 | 收集齊全後可封印 Boss（見 [07-boss-seal.md](../../07-boss-seal/SA/07-boss-seal.md)），不可消耗/丟棄 |
| 鎮靜藥丸 | 回復道具 | 回復 SAN（不超過最大 SAN） |
| 海草繃帶 | 回復道具 | 回復 HP（不超過上限） |

- F-INV-12：回復道具有「SAN 回復數值」與「HP 回復數值」兩個欄位，可各自設定。【已確認】（依 [script 分類](../../00-overview/原始需求/2026-10-03-script分類.md)）
- F-INV-13：**沒有氧氣瓶**（見 02 F-OXY-03）。【已確認】
- F-INV-14：玩家只記錄「武器（魚叉）數量」與「封印道具數量」兩種，因此回復道具**撿到即生效、不進背包**。【依 script 分類推定，待確認】

- F-INV-15：場景道具改放在寶箱裡（2026-10-03 決議）。玩家靠近寶箱按互動鍵（E / 手把 North）打開 → 動畫「晃動 → 換開箱圖 → 道具從箱口升起 → 停留 → 飛向玩家」→ **自動取得**。
  - 灰寶箱 = 海草繃帶、藍灰寶箱 = 鎮靜藥丸、黑寶箱 = 邪神雕像（封印道具）。2026-10-04：黑寶箱改為 4 個（新增一個在區塊 2-2 左側地板）。
  - 原本場景上 10 個道具位置全部換成對應顏色的寶箱；敵人掉落的道具仍為直接碰觸拾取。
  - 打開過的寶箱維持打開狀態（死亡復活不重置）。

- F-INV-16：背包畫面（2026-10-04）：
  - 開啟時遊戲暫停（時間停止），**不會受到攻擊**、SAN / 氧氣不變。
  - 左側：魚叉（**魚槍圖** `gun_icon.png`）、邪神雕像的**圖示**與數量；下方是小地圖圖例（繃帶 / 藥丸 / 雕像圖示 + 顏色）。
  - 右側：**小地圖**，只顯示**去過的區塊**（含區塊內的**台階**，淺綠細條）；去過的區塊內**未開啟的寶箱**依內容物上色（灰 = 繃帶、藍灰 = 藥丸、紫 = 邪神雕像）；**最後的邪神雕像**不論是否去過都以粉紅閃爍標示；白點 = 玩家位置；**進過 Boss 房後顯示 Boss**（紅色範圍 + 「邪神」字樣，封印後變灰，2026-10-04）。顏色都可在 `InventoryPanel` 調整。
  - 左下：精靈頭像 + 一句隨機台詞（最後的雕像出現後改成提醒位置）。
- F-INV-10：封印道具在 UI 顯示「已收集 / 總數」。
- F-INV-11：恢復類道具在數值已滿時[待確認：可否使用]。
